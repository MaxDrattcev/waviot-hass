# WAVIoT HOME для Home Assistant

Неофициальная интеграция [Home Assistant](https://www.home-assistant.io/) для устройств приложения **WAVIoT HOME**: счётчики воды и газа, датчики протечки, реле, хаб и зарядные станции для электромобилей.

## Поддерживаемые устройства

| Устройство | Что видно в Home Assistant |
|---|---|
| Phobos (розетка/реле) | Реле вкл/выкл, мощность, напряжение, ток, накопленная энергия |
| Aqua / Gefest (счётчики воды) | Расход воды, напряжение батареи |
| Betar (счётчик газа) | Расход газа, напряжение батареи |
| Ladoga (датчик протечки) | Протечка (да/нет), напряжение батареи — опрашивается отдельно и чаще остальных |
| Wallhub (хаб) | Температура, влажность |
| Wbox (зарядная станция EV) | Включение/выключение зарядки, лимит мощности (регулируемый), мощность, температура, энергия сессии, статус |

## Требования

- Работающий аккаунт WAVIoT HOME (логин и пароль от приложения)
- Home Assistant 2026.3 или новее

## Установка

### Через HACS (рекомендуется)

1. HACS → три точки в правом верхнем углу → **Custom repositories**
2. Вставить ссылку на этот репозиторий, категория **Integration**
3. Найти "WAVIoT HOME" в списке интеграций HACS → **Install**
4. Перезапустить Home Assistant

### Вручную

Скопировать папку `custom_components/waviot` из этого репозитория в `<конфиг Home Assistant>/custom_components/waviot`, перезапустить Home Assistant.

## Настройка

Настройки → Устройства и службы → Добавить интеграцию → **WAVIoT HOME** → ввести логин и пароль от аккаунта WAVIoT HOME.

Устройства и сущности создаются автоматически по всем поддерживаемым типам, найденным в аккаунте.

## Как это работает

Интеграция периодически опрашивает облако WAVIoT HOME (cloud polling) — прямого локального подключения к устройствам нет, это особенность самой платформы. Основной опрос — раз в 10 минут; протечка (Ladoga) и статус активной зарядки (Wbox) опрашиваются чаще.

**Важно:** некоторые показания (особенно у устройств на батарейках/NB-Fi) могут обновляться на стороне WAVIoT HOME нечасто — иногда раз в несколько часов. Это ограничение самой платформы, а не интеграции: показания отображаются такими, какими их в последний раз передало устройство.
