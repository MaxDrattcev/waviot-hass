# WAVIoT HOME для Home Assistant

Неофициальная интеграция [Home Assistant](https://www.home-assistant.io/) для устройств приложения **Waviot Home**: счётчики воды и газа, датчики протечки, реле, хаб и зарядные станции для электромобилей.

> Это независимый проект сообщества, не аффилированный с Waviot официально. Работает через API приложения Waviot Home (`api.waviot-home.ru`) — не путать с другими интеграциями Waviot в HACS, использующими другие сервисы (личный кабинет `lk.waviot.ru`, сторонний `curog.ru`).

## Поддерживаемые устройства

| Устройство | Что видно в Home Assistant |
|---|---|
| Phobos (розетка/реле) | Реле вкл/выкл, мощность, напряжение, ток, накопленная энергия |
| Aqua / Gefest (счётчики воды) | Расход воды, напряжение батареи |
| Betar (счётчик газа) | Расход газа, напряжение батареи |
| Ladoga (датчик протечки) | Протечка (да/нет), напряжение батареи — опрашивается отдельно и чаще остальных |
| Wallhub (хаб) | Температура, влажность |
| Wbox (зарядная станция EV) | Включение/выключение зарядки, лимит мощности (регулируемый), мощность, температура, энергия сессии, статус |

## Требования

- Работающий аккаунт Waviot (логин и пароль от приложения Waviot Home)
- Home Assistant 2026.3 или новее

## Установка

### Через HACS (рекомендуется)

1. HACS → три точки в правом верхнем углу → **Custom repositories**
2. Вставить ссылку на этот репозиторий, категория **Integration**
3. Найти "Waviot" в списке интеграций HACS → **Install**
4. Перезапустить Home Assistant

### Вручную

Скопировать папку `custom_components/waviot` из этого репозитория в `<конфиг Home Assistant>/custom_components/waviot`, перезапустить Home Assistant.

## Настройка

Настройки → Устройства и службы → Добавить интеграцию → **Waviot** → ввести логин и пароль от аккаунта Waviot.

Устройства и сущности создаются автоматически по всем поддерживаемым типам, найденным в аккаунте.

## Как это работает

Интеграция периодически опрашивает облако Waviot (cloud polling) — прямого локального подключения к устройствам нет, это особенность самой платформы Waviot. Основной опрос — раз в 10 минут; протечка (Ladoga) и статус активной зарядки (Wbox) опрашиваются чаще.

**Важно:** некоторые показания (особенно у устройств на батарейках/NB-Fi) могут обновляться на стороне Waviot нечасто — иногда раз в несколько часов. Это ограничение самой платформы Waviot, а не интеграции: показания отображаются такими, какими их в последний раз передало устройство.

## Известные ограничения

- Устройство типа Wbox может сообщать не полностью документированные коды состояния (например, при простое без зарядки) — в этом случае статус отображается как "Неизвестно", это ожидаемо и так же ведёт себя официальное приложение Waviot Home.
- Поле "лимит мощности от сети" на платформе Waviot может изменяться независимо от пользовательских настроек — диапазон регулировки лимита зарядки в интеграции зафиксирован (1.2–10 кВт) и не зависит от этого поля.
