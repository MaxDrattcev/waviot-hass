# WAVIoT HOME для Home Assistant

Неофициальная интеграция [Home Assistant](https://www.home-assistant.io/) для устройств приложения **WAVIoT HOME**: счётчики воды и газа, датчики протечки, реле, хаб и зарядные станции для электромобилей.

## Поддерживаемые устройства

| Устройство | Что видно в Home Assistant |
|---|---|
| Phobos (розетка/реле) | Реле вкл/выкл, мощность/напряжение/ток (по фазам у трёхфазных), накопленная энергия по тарифам, настройки отключения по мощности |
| Aqua / Gefest (счётчики воды) | Расход воды, напряжение батареи |
| Betar (счётчик газа) | Расход газа, напряжение батареи |
| Ladoga (датчик протечки) | Протечка (да/нет), напряжение батареи — опрашивается отдельно и чаще остальных |
| Wallhub (хаб) | Температура, влажность, длительность индикации |
| Wbox (зарядная станция EV) | Включение/выключение зарядки, лимит мощности (регулируемый), мощность, температура, энергия сессии, статус, расписание запуска/остановки, история завершённых сессий (календарь) |

На каждом устройстве также есть кнопка **«Обновить данные»** — запрашивает у облака WAVIoT свежий статус по требованию, не дожидаясь обычного опроса.

## Требования

- Работающий аккаунт WAVIoT HOME (логин и пароль от приложения)
- Home Assistant 2026.3 или новее
- Исходящий доступ с сервера Home Assistant на `waviot.dom-ik.ru:5672` (AMQP) — нужен для мгновенных событий. Если порт заблокирован файрволом/провайдером, интеграция всё равно работает, просто без мгновенных обновлений — только обычный опрос раз в 15 минут

## Установка

### Через HACS (рекомендуется)

1. HACS → три точки в правом верхнем углу → **Custom repositories**
2. Вставить ссылку на этот репозиторий, категория **Integration**
3. Найти "WAVIoT HOME" в списке интеграций HACS → **Install**
4. Перезапустить Home Assistant

### Вручную

Скопировать папку `custom_components/waviot_home` из этого репозитория в `<конфиг Home Assistant>/custom_components/waviot_home`, перезапустить Home Assistant.

### Обновление с версии, где интеграция называлась `waviot`

Домен интеграции изменился с `waviot` на `waviot_home` — прежний совпадал с другой интеграцией из каталога HACS, и они перезаписывали бы друг друга. Если вы ставили версию `0.1.0` или собирали интеграцию из репозитория раньше, обновление не подхватится автоматически:

1. Удалить в Home Assistant интеграцию **WAVIoT HOME** (Настройки → Устройства и службы).
2. Обновить интеграцию через HACS (или скопировать новую папку `custom_components/waviot_home` вручную) и убедиться, что старой папки `custom_components/waviot` в конфигурации Home Assistant больше нет — если осталась, удалить её.
3. Перезапустить Home Assistant и заново добавить интеграцию **WAVIoT HOME**.

## Настройка

Настройки → Устройства и службы → Добавить интеграцию → **WAVIoT HOME** → ввести логин и пароль от аккаунта WAVIoT HOME.

Устройства и сущности создаются автоматически по всем поддерживаемым типам, найденным в аккаунте.

## Как это работает

Интеграция периодически опрашивает облако WAVIoT HOME (cloud polling, раз в 15 минут) — прямого локального подключения к устройствам нет, это особенность самой платформы. Дополнительно протечка, реле и статус/мощность зарядки обновляются **почти мгновенно**, без ожидания следующего опроса — интеграция слушает поток событий WAVIoT HOME напрямую. Обычный опрос остаётся резервным источником истины: если мгновенное обновление по какой-то причине не дошло, следующий плановый опрос всё равно покажет актуальное состояние.

**Важно:** некоторые показания (особенно у устройств на батарейках/NB-Fi) могут обновляться на стороне WAVIoT HOME нечасто — иногда раз в несколько часов. Это ограничение самой платформы, а не интеграции: показания отображаются такими, какими их в последний раз передало устройство.
